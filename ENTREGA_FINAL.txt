🚀 QUICK START (5 MINUTOS)

Opción 1: Docker (Recomendado)
  $ cd mini-rag-pro
  $ cp mini-rag-backend/.env.example mini-rag-backend/.env
  $ nano mini-rag-backend/.env  # Agregar GEMINI_API_KEY
  $ docker-compose up -d
  # Frontend: http://localhost:3000
  # Backend: http://localhost:5000/health

Opción 2: Local
  # Backend
  $ cd mini-rag-backend
  $ npm install && npm run dev  # http://localhost:5000
  
  # Frontend (otra terminal)
  $ cd mini-rag-frontend
  $ npm install && npm run dev  # http://localhost:5173

✨ CARACTERÍSTICAS PRINCIPALES

RAG Pipeline
  User Query → Cache Check → Retrieval → Context Building
  → Prompt Engineering → Gemini API → Response Formatting
  → Cache Storage → Send to Frontend

Multi-Chat
  • Multiple conversations per user
  • Document attachment per chat
  • Query history tracking

Custom Agents
  • Predefined types (general, researcher, summarizer, etc)
  • Custom instructions per agent
  • Model configuration (temperature, topP, etc)

Document Management
  • Upload multiple formats (PDF, DOCX, TXT, HTML)
  • Automatic text extraction
  • Chunking with overlap
  • Async embedding processing

Caching Strategy
  • Redis for fast access (7-day TTL)
  • Database backup for persistence
  • Hit counter tracking

🆘 TROUBLESHOOTING RÁPIDO

Error: ECONNREFUSED 5432 (PostgreSQL)
  → Solución: docker-compose up postgres

Error: ECONNREFUSED 6379 (Redis)
  → Solución: docker-compose up redis

Error: 401 Unauthorized
  → Solución: Token expirado, hacer login nuevamente

Error: CORS error
  → Solución: Verificar FRONTEND_URL en .env

Error: Gemini API error
  → Solución: Verificar GEMINI_API_KEY en .env

Ver más en README.md sección Troubleshooting
